DỰ ÁN: WEB BÁN MŨ BẢO HIỂM – ĐỒ PHƯỢT QUẢNG TRỊ

– Công nghệ:
  Node.js + Express
  EJS
  SQLite (db/helmet.db)
  TailwindCSS
  Multer upload ảnh
  Modal sản phẩm + carousel ảnh (prev/next + swipe mobile)

– Chức năng đã làm:
  + Trang chủ bán hàng
  + Admin đăng nhập
  + Thêm / sửa / xóa sản phẩm
  + Upload nhiều ảnh cho 1 sản phẩm
  + Chọn ảnh đại diện hiển thị index
  + Click sản phẩm mở modal xem ảnh (carousel)
  + Giỏ hàng frontend
  + Gửi đơn qua email
  + UX mobile: swipe ảnh
